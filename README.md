## 👋 About Me

Hey, I'm Atharv! I got into frontend because I got tired of ugly tools, so now I just build my own. Planners, focus timers, progress trackers, dashboards, basically anything that makes my day run smoother.

I care a lot about the small stuff: smooth animations, clean spacing, and things that just feel good to use.
